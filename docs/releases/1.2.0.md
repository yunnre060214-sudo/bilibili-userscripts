# B站直播预言 1.2.0

净收益从「当前列表一个总数」改成两个数：今天，和历史以来。

## 今天

只加已经结算、而且结算时间落在浏览器本地零点到现在的硬币变化。零点整算今天，零点前一秒算昨天。比现在更晚的时间不算今天。未结算、未参与、空的硬币变化都不加进去。

## 历史以来

官方参与记录接口是：

`GET https://api.live.bilibili.com/xlive/app-ucenter/v1/elden/hsitory_user?uid=`

当前官方页面只传 `uid`，没有页码、游标或条数参数，并提示最多查看 100 条。脚本因此这样处理：

- 响应里如果有 `has_more` 或下一页游标，就逐页继续要。页与页之间间隔 400 毫秒，失败的 429 或 5xx 最多再试一次，最多 20 页。同一条预言不重复加。
- 没有继续标记时，返回不足 100 条就当作接口能给出的全部，标题写「历史以来」。
- 没有继续标记且达到 100 条，标题写「历史以来（近 100 条）」，并说明更早的记录加不进去。
- 读失败时，用当前页面上已经能看到的记录计算，标题写「历史以来（近 N 条）」，并说明这不是完整历史。当前页没有结算时间时，今天显示为「—」。

结果按登录用户缓存约 3 分钟。页面里的普通 DOM 更新不会重复请求。结算结果变了，或者本地日期过了零点，才会再读。

每条记录的加减仍然是官方的 `smh_num_change`。正数净赚，负数净亏，`0` 持平。

## 没有改动的部分

入口、确认弹窗和参与请求不变。脚本不自动下注，也不读取 Cookie 文本；历史请求只让浏览器带上预言页已经有的登录状态。
