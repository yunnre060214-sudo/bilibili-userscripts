# B站直播预言 0.3.0

把“预言”入口移到弹幕输入框上方，点击直接打开当前主播的官方预言独立页面。安装与更新 Raw 地址保持不变。

## 修改

- 新入口挂载在原生弹幕工具栏左侧三个图标之后，采用 51 × 28px 浅色按钮、粉紫青渐变边框、小图标及键盘焦点反馈。
- 删除浮动入口、嵌入式小窗、iframe 加载占位及小窗内导航。当前预言和参与历史使用官方独立页面，新标签页或新窗口由浏览器设置决定。
- 保留主播识别、8 秒超时、点击重试和油猴菜单。独立页面在点击事件中同步打开，重试及后台加载结束后不会自动弹出页面。
- 支持工具栏延迟加载和页面重新渲染；观察器在入口已挂载时直接返回，避免随每条弹幕扫描整个页面。
- 支持活动页内嵌的数字或 `/blanc/` 直播间，按各文档防止重复注入。按钮始终跟随原生弹幕区，没有工具栏时保留油猴菜单入口。
- 切换房间时中止旧请求，点击时同步校验当前路由；离开页面暂停观察与轮询，返回后恢复。

## 范围

独立页面沿用 0.2.2 的浅色渐变样式和官方 SDK 桌面确认适配。账号、请求、参与条件和手动确认流程保持原实现。未修改 BiliEcho、BiliForge 或评论楼层导出器，没有新增依赖或脚本权限。

## 验证

- 先运行新入口测试验证旧版缺少行为：24 项中 19 项按预期失败、5 项原有保护通过；实现后预言测试 37/37 通过，且未出现运行时错误。
- 实际直播页只读检查确认工具栏、左侧图标组及弹幕输入区的 DOM；新入口测试使用相同层次结构，覆盖延迟挂载、重新挂载、内嵌直播页、独立打开、异常重试、路由竞态和页面恢复。
- 官方组件本地联测通过：当前预言、历史及独立页面样式与事件正常；手动确认前无 POST，确认后一次模拟 `user_join`，刷新并显示提示。真实参与请求数为 0。
- JavaScript 语法检查通过。桌面 SDK 适配的功能代码与 0.2.2 一致。
- 全仓测试 64/65 通过。唯一失败仍为原有 `BiliForge live quality applies the latest visibility request during menu loading`，本次未修改该模块。
- 本地检查使用 jsdom，不计算实际浏览器布局。新入口的浏览器实机排版及服务器参与验收尚未独立验证。

更新后刷新整个直播页，按钮悬停提示应显示 `v0.3.0`。已打开的独立预言页面也应刷新，左上角显示“桌面交互适配已启用 v0.3.0”。
