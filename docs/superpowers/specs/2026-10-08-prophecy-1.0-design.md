# B站直播预言 1.0.0 设计

目标是把已经能打开和参与预言的脚本升级为稳定版，覆盖入口、独立页面、手动确认和异常恢复。用户要求全面升级；继续遵循已确定的简约图标、弹幕区入口、独立页面、浅色多色渐变点缀及删除适配状态标签的偏好。沿用 GitHub Raw 更新地址，直接完成实现、验证和发布。

## 范围与边界

修改现有单文件用户脚本，保持 document-start、GM_registerMenuCommand 和 unsafeWindow 权限，无新增依赖。继续使用官方预言页面与当前/历史路由；账号、资格、硬币检查及参与请求由官方组件处理，只有用户手动确认才继续参与。BiliForge、BiliEcho 和导出器不属于本次修改范围。

## 入口与恢复

保留 28px 点击区域、22px 单 SVG Logo，透明底无常驻边框。根据弹幕区背景调整线条明暗，并在背景变化时更新。普通点击打开当前主播；Shift+点击及新增油猴菜单打开参与记录，历史入口无需成功识别主播。识别结果仅在内存缓存 5 分钟，最多 32 个房间；切换房间同步核验 URL，中止旧请求，返回缓存房间无需重复请求。瞬时网络故障、服务器失败或超时最多自动重试一次，间隔 1200ms；断网提供恢复提示，联网后恢复识别。短时间重复操作按地址限制为 600ms 内一次，防止重复打开。后台暂停 DOM 观察和路由轮询，返回后恢复。保持数字、短号、blanc 及活动内嵌直播间支持。

## 独立页面

在官方当前/历史页面之外添加轻量顶部导航，提供当前预言、参与记录和刷新，沿用官方 hash 路由且保留查询参数。规则等其他路由不显示该导航。无有效主播 UID 时禁用当前预言，但记录仍能查看。页面中心最大宽度 960px，宽屏预言与历史卡片两列、窄屏单列；保留答案等宽、余额栏和官方内容。使用白底、细灰边框、粉紫青渐变点缀，不恢复任何 SDK 状态标签。

## 确认与提示

确认时锁定正文滚动并让页面内容及导航暂时不可交互，仍支持取消、Escape 和 Tab 焦点约束；结束后恢复原滚动、交互及焦点。重复弹窗取消旧请求，容器被移除时取消并恢复。隐藏或离开页面时取消尚未确认的弹窗。确保 SDK 容器被页面重建移除后仍可再次工作，防止晚加载和重复注入失效。结果提示支持无障碍播报，根据文本长度适度延长显示时间。

## 验证

扩展已有 jsdom 真实脚本交互测试，覆盖缓存与过期、联网和后台恢复、背景切换、自动重试、历史入口、重复点击、hash 导航、容器重建、滚动和焦点恢复及确认期间导航阻止。用保存的官方 SDK 和 Vue 卡片验证选择、确认、模拟提交和提示，无真实硬币交易。检查入口 CSS、官方样式和语法，运行全仓回归；公开已知的原有 BiliForge 失败基线。发布后核对 main、全部修改文件和 Raw 内容。jsdom 不提供实机布局或真实服务器验收，明确标注此限制。
