# B站直播预言 0.2.1

根据用户提供的 0.2.0 实际截图完善桌面界面。安装和更新 Raw 地址保持不变，版本升级为 0.2.1。

## 修改

- 修复答案行未设置宽度、内部 flex 子项随文字收缩的问题。答案行铺满卡片，蓝粉按钮等宽，短答案保持横排，长答案可在按钮内换行。
- 未选择时保留完整文字对比；选择后才弱化另一项。仅仍有倒计时且尚未选择的卡片显示可点击光标和悬停效果，继续由官方组件检查参与资格。
- 收紧问题与状态的间距、顶部标题区和支持比例条，余额栏由 76px 调整为 58px，并同步保留底部滚动空间。
- 嵌入页隐藏与外层提示重复的适配标签，内容顶部留白减为 12px。独立窗口保留适配标签。窄窗口缩小卡片及选项内边距。
- 增强房间号、导航和底部提示的文字对比；扩大刷新和独立窗口的点击区域，增加轻微悬停背景。

## 范围

不改变 SDK 请求实现、账号获取、官方组件事件、答案和参与状态。没有新增依赖、接口或脚本权限。仍须手动选择答案并确认后，才继续官方参与流程。

## 验证

- `npm run test:prophecy`：38/38 通过。新增嵌入页隐藏重复标签后仍能打开确认窗口的测试，先失败后通过。
- `node --check bilibili-live-prophecy.user.js`：通过。
- 本地官方组件联测：当前预言、历史、独立窗口的计算样式及交互通过。0.2.0 基线未通过新的答案行样式检查，0.2.1 通过；点击答案后、手动确认前没有 POST，确认后产生一次模拟 `user_join`（answer=2），选中状态更新，刷新一次并显示完成提示。真实参与请求数为 0。
- `npm test`：65/66 通过。唯一失败仍为原有的 `BiliForge live quality applies the latest visibility request during menu loading`（`tests/regression.test.cjs`），该模块未修改。
- jsdom 不计算浏览器布局；本次修正依据用户实际截图和官方 DOM、CSS，发布后的实际浏览器显示仍待使用复核。未声称完成新版本的真实服务器参与验收。

更新脚本后刷新整个直播页，面板底部版本应显示 `v0.2.1`。仅点击面板内的“刷新”不会替换顶层已运行的旧脚本。
