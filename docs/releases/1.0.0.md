# B站直播预言 1.0.0

把简约入口和官方独立页面升级为稳定版，覆盖页面布局、参与记录导航、背景适配与异常恢复。Raw 安装和更新地址保持不变。

## 入口与恢复

- 沿用输入框上方的单 Logo：28px 点击区域、22px SVG、透明底和淡渐变悬停效果；观察弹幕背景变化，切换明暗线条。
- 当前主播仅使用公开 GET 识别。内存缓存 5 分钟、最多 32 个房间；换房中止旧请求，同步校验路由，晚返回结果不能覆盖新主播。
- 瞬时网络故障、HTTP 429/服务器失败及超时最多自动重试一次，间隔 1200ms；无效账号/主播响应和普通 HTTP 错误仍可手动重试。断网时提供提示，联网后恢复识别。
- Shift+点击 Logo 或油猴菜单打开参与记录；识别失败也可从菜单查看记录。同一地址 600ms 内防止重复打开。
- 后台暂停入口观察与路由轮询，回到页面恢复。延迟工具栏、Vue 重建和活动页内嵌直播间继续支持。

## 独立页面与交互

- 新增轻量顶部导航：当前预言、参与记录、刷新；沿用官方 hash 路由并保留 URL 查询参数，无有效主播时禁用当前预言。规则等其他路由不显示此栏。
- 使用浅色页面、白底卡片、细边框和粉紫青渐变点缀。内容最大宽度 960px，1000px 及以上窗口双列，窄屏单列，保留等宽答案、官方支持比例和余额栏。
- 继续移除左上角 SDK 状态标签。桌面 SDK 提前/晚加载和分离的脚本窗口仍能显示官方确认流程。
- 确认时锁定滚动和背景交互；取消、Escape、隐藏或离开页面、改变路由、移除弹窗容器时均取消未确认选择并恢复原状态。Tab 焦点留在弹窗中，结束后恢复焦点。
- 重复弹窗先取消旧选择；适配容器被移除后可再次创建。结果提示增加无障碍播报，按文字长度调整显示时间，最长 8 秒。

## 保持的边界

没有新增脚本权限、依赖或持久化账号信息；BiliForge、BiliEcho 和导出器没有修改。SDK 的账号、资格检查、硬币检查及参与请求仍使用官方实现，参与始终要求手动确认，脚本不自动投注。

## 验证

- 新行为先用旧版运行：入口侧 9 项、桌面侧 9 项按预期失败；实现后全部 61 项预言测试通过，无脚本运行时错误。独立审查后新增回归：同步提示触发容器重建时取消旧确认、仅输入框更换时重新观察主题、空响应不误判为网络故障。
- 保存的官方 SDK 和 Vue 组件本地联测通过：当前、历史及独立页面正常，手动确认前 0 POST，确认后 1 次模拟 `user_join`、刷新并显示完成提示；真实参与请求数为 0。
- JavaScript 语法通过，三段 Shadow DOM 样式和官方主题 CSS 解析通过。
- 全仓 88/89 通过，唯一失败仍为原有 `BiliForge live quality applies the latest visibility request during menu loading`，本次没有改动其代码。
- jsdom 不计算真实浏览器布局。新导航和宽屏双列尚未独立进行实机排版复核，模拟提交不代表真实服务器验收。

更新后刷新整个直播页和已经打开的独立页面。悬停 Logo 可查看 `v1.0.0`。
