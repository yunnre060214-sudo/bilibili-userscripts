# B站直播预言 1.3.0

「历史以来」改为本机累计，不再只等于接口这一次返回的列表。

## 存了什么

优先使用油猴的 `GM_getValue` / `GM_setValue`，键名是 `bili-prophecy-archive-v1`。没有这个接口，或写入失败时，改用预言页的 `localStorage`。两者都不可用时，不保存，净收益退回本次接口或当前页面。

每个 B 站 UID 一份档案。只保存已经结算并且参与过的记录：预言编号、结算时间、硬币变化、题干、主播名。同一编号只留一条。页面上能看到结算时间、但还没有编号的记录，会先按时间、变化、题干和主播名暂存；接口稍后带回编号时再合并，避免加两次。

单个账号最多 2000 条。超出后丢掉结算时间最早的，并取消「完整历史」标记。档案版本不对或内容损坏时丢掉旧档，重新开始，不让页面报错。

## 标题

- 从未遇到过 100 条上限，累计就是接口能给出的全部：标题为「历史以来」。
- 曾经一次读到满 100 条，或档案被截断：标题为「历史以来（自 YYYY-MM-DD 起累计）」。日期是这个账号开始在本机保存的那一天。更早、当时没读到的记录不在合计里。
- 「今天」也用这份档案，只加结算时间在浏览器本地零点到现在的记录。

未结算、未参与、门票和预计奖励仍然不计入。

## 验证

更新后刷新直播页和已经打开的预言页。悬停 Logo 应显示 `v1.3.0`。
