# B站直播预言 1.0.0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task in the current session.

**Goal:** Upgrade the existing standalone prediction userscript into a reliable, polished stable release.

**Architecture:** Preserve the official Vue components and SDK request implementation. Extend the existing room entry and desktop adapter inside the distributable single file; isolate workspace navigation, room lifecycle and dialog state in their own functions.

**Tech Stack:** JavaScript, Shadow DOM, native browser APIs, node:test, jsdom 26.1.0.

**Spec:** `docs/superpowers/specs/2026-10-08-prophecy-1.0-design.md`

## Global Constraints

- Version 1.0.0; unchanged GitHub Raw URL, dependencies and script grants.
- A 28px transparent icon entry above the danmaku input; standalone opening only.
- Account, eligibility and participation requests remain official; confirmation remains manual.
- No SDK status badge; preserve light surfaces and pink/lilac/cyan accents.
- GET retries: at most one automatic retry after 1200ms. Memory cache: 5 minutes, 32 rooms. Open throttle: 600ms per URL.

## Review Focus

- Cached short-room results must expire and cannot override another room's late lookup.
- Offline/hidden pages must not loop requests or reopen windows on reconnect.
- Native toolbars replaced with a different background must receive one working icon.
- Unknown hash routes must retain official navigation and hide the custom workspace.
- Removed containers and overlapping dialogs must restore scroll, inert state and focus.
