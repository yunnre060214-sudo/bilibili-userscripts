# B站直播预言 0.2.0

在用户确认 0.1.2 成功运行后，升级桌面界面。继续使用官方组件和参与流程，安装与更新地址保持不变。

## 界面

- 448px 桌面面板、蓝粉配色、SVG 图标、标题和房间信息、分段导航、连接状态与独立工具栏。
- 官方预言及历史组件使用浅色卡片，增强题目、选项、已选状态、支持比例和硬币余额的层级。
- 重做确认窗口与消息提示，支持取消、Escape、Tab 和 Shift+Tab 焦点约束。
- 加载卡片占位，15 秒仍未收到 load 时释放占位并给出刷新或独立窗口提示；关闭、切换和页面恢复均会释放。
- 窄屏及矮屏布局，遵循 prefers-reduced-motion。规则说明等非预言、历史路由保持官方样式。

## 实现范围

保留 SDK 启动前适配、已缓存实例适配和同源 iframe 后备适配。官方组件仍拥有答案、状态、事件、账号和请求处理；脚本只添加样式与桌面交互界面，不自行提交答案，不读取 Cookie。没有新增外部依赖或权限。

## 验证

- 37 项预言测试通过。新增加载反馈、加载超时恢复、关闭时清理、页面恢复清理和确认窗口焦点约束五项测试，均先失败后通过。
- 当前官方 SDK 和 ListItem 组件本地联测：新样式下的题目、答案和确认窗口可读；点击选项后、手动确认前没有 POST；手动确认后产生一次模拟 user_join（answer=2），刷新一次并显示完成提示。真实参与网络请求数为 0。
- 语法检查通过；全仓 64/65 通过。唯一失败为此前已有的 `BiliForge live quality applies the latest visibility request during menu loading`，本次未修改该模块。
- 作者完成自查，没有独立审查。云浏览器不能打开本地测试文件，尚未完成浏览器视觉检查。0.2.0 的实际显示和服务器提交仍待真实使用验证。

更新后刷新整个直播页面，底部版本应显示 `v0.2.0`。
