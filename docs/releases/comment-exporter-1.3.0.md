# 评论楼层导出器 1.3.0

「导出为 MD」只有在 Tampermonkey 浏览器 API 模式返回完成回执后才显示「已导出」。原生模式直接提供「保存文件」；自动下载失败、被取消或 60 秒内未收到回执时，也保留已生成的 Markdown。手动保存由点击触发，提示只确认已向浏览器发出请求，文件是否保存成功可在浏览器下载记录中查看。迟到的回调不会把已超时的任务改成成功。

评论原生三点菜单新增「复制到剪贴板」，复制与文件一致的 Markdown。接口标注或实际读取的回复超过 200 条时，提前停止复制任务；最终 Markdown（包含字幕）超过 256 KiB 时同样不写入剪贴板。两种情况都会提示使用「导出为 MD」，下载不受复制上限限制。

本地测试覆盖下载回执、失败与超时、手动保存按钮、复制完成回执、超限拦截和原生菜单交互。全仓 Node 测试 188/189 通过，唯一失败为原有的 BiliForge 直播画质时序测试。Chromium 下载冒烟检查因环境限制未能启动，未在真实 Tampermonkey 环境复现原先的偶发问题。
