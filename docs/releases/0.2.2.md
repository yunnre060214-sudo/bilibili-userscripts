# B站直播预言 0.2.2

按用户提供的两张 BiliEcho 截图及入口按钮截图重做预言界面的视觉样式，采用白底和粉、紫、青渐变点缀。安装与更新 Raw 地址保持不变。

## 修改

- 入口采用 42px 浅色按钮、三色渐变勾边、17px 图标和轻阴影；打开状态使用对应渐变，键盘焦点为细轮廓。
- 面板采用浅色三色渐变标题栏，合并标题与直播间信息，去掉英文装饰标题；导航改为独立细边框按钮，并增加渐变细线点缀。
- 预言及历史卡片采用白底、中性灰边框，答案按钮为浅蓝紫、浅粉紫渐变；选中状态继续使用边框与文字层级区分。
- 确认窗口采用同一渐变标题栏、灰色内容框、粉蓝按钮和彩色细线。消息提示、加载占位和重试入口也统一浅色样式。
- 沿用 0.2.1 的答案等宽布局、状态强调、紧凑余额栏及嵌入页重复标签处理。

## 范围

本次调整 CSS 和显示结构，官方账号、请求、参与条件、SDK 适配和手动确认行为保持原实现。BiliEcho 脚本未修改，没有新增依赖或脚本权限。

## 验证

- 全部 38 项预言测试通过，覆盖选择后的确认、取消、Escape、Tab 焦点约束、SDK 启动与晚加载、同源 iframe 适配及房间路由行为。
- 官方组件本地联测：当前预言、历史、独立窗口的样式和事件检查通过；手动确认前无 POST，确认后有一次模拟 `user_join`（answer=2），刷新一次并显示结果提示。真实参与请求数为 0。
- JavaScript 语法检查通过；外层 CSS 解析通过，入口渐变背景层和装饰线语义检查通过。
- `npm test`：65/66 通过。唯一失败仍为原有 `BiliForge live quality applies the latest visibility request during menu loading`（`tests/regression.test.cjs`），本次未改动该模块。
- 本地检查使用 jsdom，不计算实际浏览器布局。新样式的浏览器实机显示和服务器参与验收尚未独立验证。

更新脚本后刷新整个直播页，面板底部版本应显示 `v0.2.2`。
