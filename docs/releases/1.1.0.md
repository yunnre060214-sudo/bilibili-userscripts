# B站直播预言 1.1.0

新标签页里的预言改成单列，标出最新一条，并显示硬币净收益。安装地址不变。

## 排版

- 当前预言和参与记录都按从上到下阅读，宽屏不再左右拆成两列。内容最宽 840px，余额栏与内容同宽。
- 题目单独占一行。当前预言的门票、倒计时或结算结果排在题目下面；两个选项仍等宽并排。
- 参与记录分成题目、状态、正确答案、净收益、主播。状态做成圆角标签。
- 最新一条使用粉色「新」标记，卡片边框也更明显。

## 最新一条怎么判断

- 参与记录有结算时间时，取时间最晚的一条。时间相同保留列表里靠前的那条。非法日期不参与比较。
- 「进行中」「等待结算」或「未开始」只有排在所有已结算记录之前时，才把其中第一条当作最新。
- 当前预言没有结算时间。按官方列表把第一条标成最新。官方刷新时会把新出现的题目插到最前。

## 净收益

参与记录的「硬币」就是官方接口的 `smh_num_change`，脚本不重新计算倍率，也不另外请求接口：

- 正数：净赚
- 负数：净亏
- `0`：持平
- `--`、空白或其他非数字：未结算或未参与，不计入合计，也不当成 0

列表顶部显示已加载记录的合计，并写明有几场计入、几场未结算。参与记录最多 100 条，合计不会超出这个范围。

当前预言页只在结算后显示带正负号的结果。脚本把这个数标成「净收益」并合计。门票金额，以及进行中的「预言成功得 N 硬币」，都是预计或成本，不计入。

## 没有改动的部分

入口、主播识别、确认弹窗、官方参与请求和权限都保持 1.0.0。脚本仍不自动选择或提交，不读取、保存或上传 Cookie。
