# 评论楼层导出器 1.2.0

视频字幕与评论保持一次下载，重点修正长楼阅读、Markdown 渲染与请求生命周期。仍通过原生评论菜单触发，交付一个零运行时依赖的 `.user.js` 文件。

## 排版与可追溯性

- 文件头只保留来源、楼层概览、导出时间和必要提示，并提供跳转链接。统计与异常索引移至文末。
- 字幕按停顿、时长和字数合并成自然段，句间用空格连接，保留重复台词与单条字幕内的换行；不补标点、不增加时间戳。
- 评论正文移出引用块，多行正文和关系提示在 CommonMark 中保持换行。HTML、注释和 Markdown 结构符号按原文显示；配图采用安全的 HTTPS 链接。
- 标记层主与同一 UID 的发言序次，同名不同 UID 不合并。每条回复仍保留具体父消息链接，L1 也不省略，以免只靠层级猜回复对象。
- 根评论不再重复列出全部直接回复；非根评论的大分叉仍有完整索引。深链压缩保留根节点、L1 入口及最后三跳。
- 缺失上游父消息时，保留分支内已确认的深度与路径，明确标记“断链”，不将局部深度伪装为距根深度。

[查看完整 Markdown 示例](../examples/comment-thread-1.2.0.md)。示例使用虚构视频编号和评论，不用于验证真实 B 站数据。

## 代码与故障处理

- 每次打开菜单更新上下文，避免复用旧标题、链接或种子评论；限定组件宿主上的数据回退，不扫描整页。
- 区分分页结束、重复页、分页上限和接口计数差额。差额原因保持未知，不将其直接归因于删除或隐藏。
- 将请求参数命名为 `maxAttempts`，明确表示总尝试次数。字幕瞬时失败最多重试一次；HTTP 403 等不可重试错误直接返回。
- B 站业务响应与字幕 CDN JSON 分开校验。无字幕轨道时省去重复请求；存在轨道却没有链接时提示登录或访问权限问题。
- 新任务能中断旧请求、分页等待和重试退避。仍保留单一取消回调，因为当前链路按顺序请求，无需为不存在的并发引入额外管理层。
- 清理旧菜单注入定时器，复用 Toast 节点和单一定时器。保留 1.1.1 修正后的域名权限与 CDN 凭据隔离。
- 移除来源链接中的分享追踪参数，AV 页面补全已确认的 BV 和视频标题。

## 验证

- 字幕与 1.2.0 专项测试：44/44 通过。
- 全仓 Node 测试：155/156 通过。唯一失败为原有 BiliForge 直播画质时序测试，本版未修改该模块。
- CommonMark 解析后检查正文换行、HTML 安全、关系换行和锚点完整性。另覆盖 1000 层完整链及断链、大分叉、原文保留、计数差额、取消、GM 文本响应与重试、菜单上下文更新。
- 浏览器 smoke test 已包含读取实际元数据的 GM 适配层和 fetch 回退。它仍是模拟接口，不等同于 Tampermonkey 沙箱或真实 CDN CORS 验证。当前环境无可用 Chromium 二进制，未执行该浏览器测试；新版真实扩展与线上下载尚未复测。

```sh
npm ci
node --test tests/exporter-12.test.cjs tests/exporter-subtitles.test.cjs
npm test
```

纯 VM 检查不在顶层加载 DOM 或渲染器依赖；完整测试通过 `npm ci` 安装 `jsdom` 和 `commonmark`。不在生产脚本内增加全局测试钩子。

## 固定样本对比

同一组 500 条直接回复与 1000 条字幕，对比 1.1.1 和 1.2.0：

| 指标 | 1.1.1 | 1.2.0 |
| --- | ---: | ---: |
| Markdown 行数 | 5557 | 3101 |
| UTF-8 字节数 | 123318 | 102946 |

该固定样本行数减少 44.2%，体积减少 16.5%。所有 500 条回复及 1000 条字幕仍保留。具体收益取决于原文长度、回复结构与字幕停顿，不代表所有视频的固定压缩率。
